# 💜 Happy Birthday Shrestha

An interactive birthday surprise website created with ❤️ by Harman.

## Features

- 🎉 Animated Welcome Screen
- 💜 Purple Aesthetic Theme
- 📸 Photo Gallery
- 🎵 Music Section
- 🧠 Memory Quiz
- 😀 Guess the Emoji
- 🎂 Birthday Trivia
- 🧩 Puzzle
- 🎆 Fireworks Finale
- 📱 Mobile Responsive

## How to Add Photos

Replace:

photos/photo1.jpg
photos/photo2.jpg
...
photos/photo6.jpg

with your own photos.

## Add Music

Put your MP3 inside:

music/song.mp3

## Upload to GitHub Pages

1. Create a GitHub repository.
2. Upload all project files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from Branch**.
5. Select the `main` branch and `/root`.
6. Save.

Your website will be available at:

https://YOUR_USERNAME.github.io/Happy-Birthday-Shrestha/
ENJOY! 💕
